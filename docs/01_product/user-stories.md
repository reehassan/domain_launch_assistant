# User Stories

> **What can the user actually do?**

## 1. Business Idea

### US-01 — Describe Business

**As a founder,**
I want to describe my business idea in natural language,
**so that** the application can understand what I am building.

### US-02 — Create Launch Project

**As a founder,**
I want my business idea to be saved as a launch project,
**so that** I can continue working on it without starting over.

---

## 2. Brand Name Generation

### US-03 — Generate Brand Names

**As a founder,**
I want to generate relevant brand names from my business idea,
**so that** I can discover potential names for my business.

### US-04 — Understand Name Suggestions

**As a founder,**
I want each suggested brand name to include a short explanation,
**so that** I understand why the name fits my business.

### US-05 — Generate More Names

**As a founder,**
I want to generate another set of brand names,
**so that** I can explore different naming options.

---

## 3. Domain Discovery

### US-06 — Generate Domain Candidates

**As a founder,**
I want domain candidates to be generated from a brand name,
**so that** I can see which domains could represent my business.

### US-07 — Check Domain Availability

**As a founder,**
I want to check real-time domain availability,
**so that** I don't choose a brand whose domain is unavailable.

### US-08 — See Domain Status

**As a founder,**
I want to clearly see whether a domain is available or taken,
**so that** I can quickly compare my options.

### US-09 — Compare Domains

**As a founder,**
I want to compare multiple domain candidates,
**so that** I can choose the best available domain for my business.

---

## 4. Domain Selection

### US-10 — Select Domain

**As a founder,**
I want to select an available domain,
**so that** it becomes the domain for my launch project.

### US-11 — Change Selected Domain

**As a founder,**
I want to change my selected domain before launch,
**so that** I can switch to a better available option.

---

## 5. Launch Readiness

### US-12 — View Launch Status

**As a founder,**
I want to see the current launch status of my selected domain,
**so that** I know what has been completed and what still needs attention.

### US-13 — Check DNS Readiness

**As a founder,**
I want to check whether my domain's DNS configuration is ready,
**so that** I know whether the domain is technically ready for launch.

### US-14 — Configure DNS

**As a founder,**
I want to configure the required DNS records for my selected domain,
**so that** I can connect the domain to my application or website.

### US-15 — Verify DNS Configuration

**As a founder,**
I want to verify my DNS configuration,
**so that** I can confirm that my domain is correctly configured.

### US-16 — See Launch Checklist

**As a founder,**
I want to see a checklist of launch requirements,
**so that** I can clearly understand what remains before launch.

Example:

```text
✓ Business idea defined
✓ Brand name selected
✓ Domain available
✓ Domain selected
✓ DNS configured
✓ DNS verified
```

---

## 6. Launch Project Management

### US-17 — View Previous Project

**As a founder,**
I want to reopen my launch project,
**so that** I can continue working on it later.

### US-18 — View Generated Names

**As a founder,**
I want to view the brand names generated for my project,
**so that** I can revisit previous naming ideas.

### US-19 — View Domain Search Results

**As a founder,**
I want to view previously checked domains,
**so that** I don't have to repeat domain searches unnecessarily.

---

# 7. MVP User Journey

The primary MVP journey is:

```text
US-01  Describe business
   ↓
US-03  Generate brand names
   ↓
US-06  Generate domain candidates
   ↓
US-07  Check real-time availability
   ↓
US-09  Compare domains
   ↓
US-10  Select domain
   ↓
US-12  View launch status
   ↓
US-13  Check DNS readiness
   ↓
US-14  Configure DNS
   ↓
US-15  Verify DNS
   ↓
Launch Ready
```

The MVP is complete when a founder can successfully follow this journey from **business idea to a launch-ready domain**.
